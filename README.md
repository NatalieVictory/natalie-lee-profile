# Natalie Lee 個人網站

純 HTML + CSS 個人網站，包含關於我、專業經歷、學歷與專業參與。

## GitHub Pages 發布

1. 建立名為 `natalie-lee-profile` 的 GitHub repository。若使用 GitHub Free，請設為 Public。
2. 將此壓縮檔解壓縮，把全部內容上傳到 repository 的根目錄。`index.html` 須位於根目錄，並保留 `assets` 資料夾。請勿只上傳 ZIP 或現有網站連結。
3. 確認 `.nojekyll` 已上傳；若檔案管理員不顯示此檔，可在 GitHub 根目錄建立同名空檔。
4. 進入 Settings → Pages。Build and deployment 的 Source 選 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，按 Save。
6. 等待部署成功後，使用 Pages 設定頁所顯示的正式網站網址分享。

所有網頁連結與資產路徑均為相對路徑，可用於 GitHub Pages project site。
網站的職稱、日期、學歷及組織資訊依提供的履歷整理。

## 編輯

- index.html：關於我
- experience.html：專業經歷
- education.html：學歷
- affiliations.html：專業參與
- styles.css：共用版型，已設計 375px 與 1280px 響應式尺寸
- assets/：照片及 PDF 履歷
